## TCGplayer Collection Exporter

Export your TCGplayer collection HTML file to a downloadable spreadsheet (CSV or XLSX). Now you can backup and view your collection without worring about accidently changing card quantities!

**Instructions:**

1. Open your [TCGplayer](https://www.tcgplayer.com) collection page and wait for the table to finish loading.  
2. Press **Ctrl+S** (Windows) or **Cmd+S** (Mac).  
3. Choose **“Webpage, Complete”** and save the `.html` file.  
4. Upload that `.html` file here (or copy the table `outerHTML` from DevTools and save it).
